### RESUME SCREENING & JOB ROLE CLASSIFICATION
**Machine Learning · NLP**

A machine-learning project that processes resume text and classifies resumes into broader job-role categories.

The project explores:

- Data preprocessing and cleaning
- TF-IDF feature extraction
- Unigrams and bigrams
- Logistic Regression
- Class balancing
- GridSearchCV for hyperparameter tuning
- Accuracy, Precision, Recall and F1-score
- Confusion Matrix
- Model saving and reuse

The project also explores the limitations of TF-IDF-based approaches and possible future improvements using more advanced NLP models.

**Technologies:** `Python` `Pandas` `NumPy` `Scikit-learn` `Matplotlib`

→ **[View ACM Work Repository](https://github.com/Aish25-sketch/ACM_work)**
